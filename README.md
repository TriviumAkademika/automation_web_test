# 🧪 Web Automation Testing – SIAKAD (Selenium)

Automation testing untuk aplikasi web **Sistem Informasi Akademik (SIAKAD)** menggunakan **Selenium WebDriver**.

Automation ini difokuskan untuk memverifikasi fitur-fitur utama berdasarkan **role pengguna** pada aplikasi web.

---

## 🛠️ Teknologi

- Selenium WebDriver
- Web Automation (UI Testing)
- Browser Automation (Chrome)

---

## 🎯 Scope Automation (Saat Ini)

Automation yang telah diimplementasikan saat ini hanya mencakup:

### 👤 Role
- Dosen

### ✅ Skenario yang sudah tersedia

- Login sebagai dosen
- Menambahkan data dosen baru

---

## 🔐 Cakupan Hak Akses

Skenario automation memperhatikan pembatasan hak akses berdasarkan role.

Automation hanya dijalankan menggunakan akun dengan role:

- Dosen

Validasi yang dilakukan meliputi:

- keberhasilan login
- akses halaman sesuai role
- keberhasilan proses penambahan data dosen

---

## 🚧 Fitur Lainnya (Incoming)

Skenario automation untuk fitur berikut masih dalam tahap:

- proses pengerjaan
- eksplorasi kebutuhan automation
- perancangan test scenario

Fitur yang direncanakan untuk ditambahkan:

- Manajemen jadwal
- FRS
- Manajemen nilai
- Manajemen pengguna (role lain)

---

## 📌 Catatan Pengembangan

Automation testing ini dikembangkan secara bertahap menyesuaikan dengan:

- perkembangan fitur aplikasi
- stabilitas UI
- kebutuhan pengujian untuk tim developer dan QA

Fokus utama saat ini adalah membangun baseline automation pada role dosen sebelum memperluas cakupan ke role lainnya.
